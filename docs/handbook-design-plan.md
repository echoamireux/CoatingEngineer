### 一、涂布基础名词库 (Glossary)

#### 1.1 基础术语

| 术语         | 英文               | 定义                                           |
| ------------ | ------------------ | ---------------------------------------------- |
| **涂布量**   | Coating Weight     | 单位面积基材上涂布物质的质量，通常以 g/m² 表示 |
| **湿涂布量** | Wet Coating Weight | 涂布后未干燥状态的涂布量 (g/m²)                |
| **干涂布量** | Dry Coating Weight | 干燥后的涂布量，等于湿涂布量×固含量            |
| **固含量**   | Solid Content      | 涂料中非挥发性物质的质量百分比 (%)             |
| **粘度**     | Viscosity          | 流体抵抗流动的内摩擦力，单位 mPa·s 或 cP       |
| **表面张力** | Surface Tension    | 液体表面分子间作用力，单位 mN/m (dyne/cm)      |
| **润湿**     | Wetting            | 液体在固体表面铺展的能力                       |
| **接触角**   | Contact Angle      | 液滴与固体表面的夹角，<90°亲水，>90°疏水       |
| **流平**     | Leveling           | 涂层自发消除表面不平整的过程                   |

### 三、涂布工艺理论 (Coating Process Theory)

#### 3.1 狭缝涂布 (Slot Die Coating) - 重点

##### 2.1.1 基础参数定义

| 参数     | 符号 | 单位   | 说明               |
| -------- | ---- | ------ | ------------------ |
| 涂布间隙 | G    | μm     | 模头唇口到基材距离 |
| 湿膜厚度 | H    | μm     | 涂布后未干燥膜厚   |
| 狭缝宽度 | b    | μm     | 模头内部狭缝间隙   |
| 涂布速度 | V    | m/min  | 基材线速度         |
| 流量     | Q    | mL/min | 泵供液流量         |
| 涂布宽度 | W    | mm     | 有效涂布宽度       |

##### 2.1.2 核心理论公式

**质量守恒方程:**

$$H = \frac{Q}{V \cdot W}$$

**毛细数 (Capillary Number):**

$$Ca = \frac{\eta \cdot V}{\sigma}$$

- η: 动态粘度 (Pa·s)
- V: 涂布速度 (m/s)
- σ: 表面张力 (N/m)

**韦伯数 (Weber Number):**

$$We = \frac{\rho \cdot V^2 \cdot H}{\sigma}$$

**间隙比:**

$$G^* = \frac{G}{H}$$

**临界最小湿膜厚度 (Ruschak公式):**

$$H_{min} = 0.65 \cdot G \cdot Ca^{2/3}$$

##### 2.1.3 涂布窗口图 (Coating Window) - 交互式

```
┌─────────────────────────────────────┐
│         涂布窗口图 (Ca vs G/H)       │
├─────────────────────────────────────┤
│  G/H ↑                              │
│   3.0├─────────────────────────     │
│      │    [气泡夹带]                │
│   2.5├───────●────────────────     │
│      │      ╱ ╲                    │
│   2.0├────╱ 稳定涂布区 ╲──────     │
│      │  ╱       ⬤       ╲        │
│   1.5├╱─────────────────────╲─    │
│      │    [断液/Ribbing]           │
│   1.0├─────────────────────────     │
│      └──────────────────────→ Ca  │
│        0.01   0.1    1.0   10     │
│                                     │
│  [调整参数] [重置] [导出]            │
└─────────────────────────────────────┘
```

**交互功能:**

- 拖拽当前工艺点查看稳定性
- 输入参数自动计算Ca和G/H
- 显示工艺点是否在稳定窗口内

##### 2.1.4 模头内部流动

**狭缝内压降 (泊肃叶流动):**

$$\Delta P_{slot} = \frac{12 \eta Q L}{W b^3}$$

- L: 狭缝长度 (Land length)
- b: 狭缝间隙

**模头入口压降:**

$$\Delta P_{entrance} \approx 0.5 \rho V_{slot}^2$$

**总供液压力:**

$$P_{supply} = \Delta P_{slot} + \Delta P_{entrance} + \Delta P_{pipe}$$

##### 2.1.5 缺陷机理与临界条件

| 缺陷                       | 临界条件            | 机理                            |
| -------------------------- | ------------------- | ------------------------------- |
| Ribbing (条纹)             | Ca > Ca_critical    | 界面不稳定性，需降低Ca或增大G/H |
| Air Entrainment (气泡夹带) | G/H > 2.5 或 Ca过小 | 动态润湿线失稳                  |
| Chatter (震纹)             | 机械振动            | 系统阻尼不足                    |
| Streaks (纵向条纹)         | 模唇缺陷/颗粒       | 局部流场扰动                    |

#### 3.2 凹版涂布 (Gravure Coating)

##### 2.2.1 网穴参数

| 参数     | 典型值      | 说明         |
| -------- | ----------- | ------------ |
| 线数 LPI | 80-200      | 每英寸网穴数 |
| 深度 D   | 20-80 μm    | 网穴深度     |
| 开口角   | 120-140°    | 网穴侧壁角度 |
| 容积     | 20-80 mL/m² | 理论储液量   |

##### 2.2.2 涂布量计算

**理论涂布量:**

$$W_{wet} = \frac{V_{cell} \cdot \eta_{transfer}}{1000}$$ (g/m²)

- $V_{cell}$: 网穴容积 (mL/m²)
- $η_{transfer}$: 转移效率 (60-90%)

**转移效率影响因素:**

- 刮刀角度: 55-65°最佳
- 刮刀压力: 1-3 N/cm
- 速度比: 凹版辊速/基材速度

##### 2.2.3 刮刀系统

**刮刀压力分布:**

$$p(x) = p_0 \cdot e^{-x/\lambda}$$

- λ: 特征衰减长度，与刮刀刚度相关

### 四、测试方法体系 (Testing Methods)

#### 4.1 动态热机械分析 (DMA)

##### 3.1.1 基本原理

对样品施加正弦应力或应变，测量响应：

$$\sigma(t) = \sigma_0 \sin(\omega t)$$
$$\varepsilon(t) = \varepsilon_0 \sin(\omega t - \delta)$$

**储能模量 (Storage Modulus):**

$$G' = \frac{\sigma_0}{\varepsilon_0} \cos\delta$$

**损耗模量 (Loss Modulus):**

$$G'' = \frac{\sigma_0}{\varepsilon_0} \sin\delta$$

**损耗因子:**

$$\tan\delta = \frac{G''}{G'}$$

##### 3.1.2 玻璃化转变温度Tg测定

| 方法     | 定义               | 特点             |
| -------- | ------------------ | ---------------- |
| tanδ峰值 | tanδ最大值对应温度 | 最常用，数值最高 |
| G'onset  | G'开始下降的拐点   | 工程应用较多     |
| G''峰值  | G''最大值          | 介于两者之间     |

##### 3.1.3 时温等效原理 (TTS)

**WLF方程:**

$$\log a_T = \frac{-C_1(T-T_r)}{C_2 + (T-T_r)}$$

- $a_T$: 移位因子
- $T_r$: 参考温度
- $C_1, C_2$: WLF常数 (通用值: C₁≈17.4, C₂≈51.6K)

##### 3.1.4 交联密度计算

从橡胶态平台模量：

$$\nu_e = \frac{G'_N}{RT}$$

- $ν_e$: 交联密度 (mol/m³)
- $G'_N$: 橡胶态平台模量 (Pa)
- R: 气体常数
- T: 绝对温度 (K)

---

#### 4.2 凝胶分率 (Gel Fraction)

##### 3.2.1 原理与方法

索氏提取法：溶剂萃取可溶分（溶胶），剩余为不溶分（凝胶）

**计算公式:**

$$Gel\% = \frac{m_{after}}{m_{before}} \times 100\%$$

##### 3.2.2 标准条件

| 参数     | 推荐值             |
| -------- | ------------------ |
| 溶剂     | 乙酸乙酯 或 甲苯   |
| 提取时间 | 24-48 小时         |
| 样品量   | 0.5-1.0 g          |
| 干燥条件 | 60°C真空干燥至恒重 |

##### 3.2.3 与性能关系

| 凝胶分率 | 交联程度 | 性能特征         |
| -------- | -------- | ---------------- |
| < 30%    | 轻交联   | 高初粘，低内聚力 |
| 30-60%   | 中等交联 | 平衡性能         |
| > 60%    | 高交联   | 高内聚力，低初粘 |

---

#### 4.3 流变分析 (Rheology)

##### 3.3.1 稳态剪切

**幂律流体模型:**

$$\eta = K \cdot \dot{\gamma}^{n-1}$$

- K: 稠度系数
- n: 流动指数 (n<1 剪切稀化, n=1 牛顿流体, n>1 剪切增稠)

**Carreau模型:**

$$\eta = \eta_\infty + \frac{\eta_0 - \eta_\infty}{[1+(\lambda\dot{\gamma})^2]^{(1-n)/2}}$$

##### 3.3.2 涂布相关参数

| 工艺环节  | 剪切速率 (s⁻¹) |
| --------- | -------------- |
| 储存/静置 | 0.01-1         |
| 泵输送    | 10-100         |
| 狭缝模头  | 100-10,000     |
| 凹版转移  | 1,000-100,000  |

##### 3.3.3 触变性测试 (3ITT)

三段阶跃剪切测试：

1. 低剪切 (0.1 s⁻¹) - 初始结构
2. 高剪切 (100 s⁻¹) - 结构破坏
3. 低剪切 (0.1 s⁻¹) - 结构恢复

**恢复率:**

$$Recovery\% = \frac{\eta_{recovered}}{\eta_{initial}} \times 100\%$$

### 五、问题诊断体系 (Troubleshooting)

#### 5.1 涂布外观缺陷

| 缺陷现象         | 可能原因           | 机理分析       | 处理方案           |
| ---------------- | ------------------ | -------------- | ------------------ |
| **拉丝/Ribbing** | 粘度高、Ca超临界   | 界面不稳定性   | 降粘/减速/增大间隙 |
| **边缘堆积**     | 边缘效应、挥发梯度 | Marangoni流动  | 边缘遮蔽/流平剂    |
| **针孔**         | 消泡剂过量、污染   | 表面能不匹配   | 减消泡/清洁/电晕   |
| **橘皮**         | 流平不足、Bénard胞 | 热对流不稳定   | 慢干溶剂/延长流平  |
| **鱼眼**         | 油/硅污染          | 局部表面张力差 | 彻底清洁/等离子    |
| **条纹(纵向)**   | 模唇刮伤/颗粒      | 局部流场扰动   | 清洁模头/过滤胶液  |
| **气泡夹带**     | G/H过大、速度过快  | 动态接触线失稳 | 减小间隙/降低速度  |

#### 5.2 干燥异常

| 缺陷现象 | 可能原因           | 机理分析          | 处理方案            |
| -------- | ------------------ | ----------------- | ------------------- |
| **起泡** | 溶剂沸腾、升温过快 | 蒸发率>扩散率     | 梯度升温/低沸点先驱 |
| **结皮** | 表干过快           | 表层固化封闭      | 降初温/慢干溶剂混合 |
| **龟裂** | 收缩应力、涂层过厚 | 干燥应力>内聚力   | 分层涂布/柔性底涂   |
| **白化** | 吸湿、相分离       | 水分凝结/相容性差 | 控制湿度/调整配方   |

#### 5.3 性能不良

| 问题         | 可能原因           | 机理           | 处理方案           |
| ------------ | ------------------ | -------------- | ------------------ |
| **初粘差**   | Tg高、润湿不足     | 分子链移动受限 | 降Tg/增增粘树脂    |
| **剥离力低** | 润湿不良、表面能低 | 界面粘结不足   | 电晕/底涂/配方调整 |
| **保持力差** | 交联不足、Tg过低   | 内聚力不足     | 增交联/提高Tg      |
| **残胶**     | 过交联、基材渗透   | 界面>内聚      | 降交联/离型处理    |
| **老化降解** | UV/热氧化          | 链断裂/氧化    | 抗氧剂/UV稳定剂    |
